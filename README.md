# Amin360IT — Portfolio Website

> Personal portfolio of **MD. ASADUZZAMAN (AMINUR)** — Software, Web & Digital Solutions.
> Live at: <https://amin360it.github.io>

A single-file, dependency-light portfolio built as a fully client-side SPA. No build step, no framework install — just open `index.html`.

---

## 🛠 Tech Stack

| Layer      | Technology                                        |
|------------|---------------------------------------------------|
| UI Logic   | Vue 3 (CDN, Composition API)                      |
| Styling    | Tailwind CSS (CDN) + custom CSS design system     |
| Effects    | Three.js (interactive particle field), AOS        |
| Icons      | Font Awesome 6 + Google Material Icons            |
| Forms      | Web3Forms (contact) + honeypot spam protection    |
| Hosting    | GitHub Pages                                      |

## 📄 Sections

Home (typed headline + animated stat counters) · About · Services (7 categories, filterable pills) · Tech Stack marquee · Projects (filterable grid, detail modals with case studies) · Process · Testimonials carousel · Clients · CTA · Contact form · Footer

## ✨ Highlights

- 🌗 **Dark / light theme** with anti-FOUC boot script + `prefers-color-scheme` sync
- 🖱️ **Custom cursor** — GPU-accelerated (`translate3d`), instant dot + trailing ring, hover/press feedback
- 🎨 **Animated brand identity** — gradient-looping brand name in header, preloader & footer; pulsing logo glow
- ♿ **Accessible** — semantic landmarks, ARIA tablist/dialog patterns, keyboard-operable project cards, labeled icon buttons
- 🔍 **SEO ready** — canonical URL, Open Graph / Twitter cards, JSON-LD `ProfessionalService` schema
- ⚡ **Zero build pipeline** — everything ships in one HTML file

## 🚀 Run Locally

```bash
# just open it
start index.html
```

Or serve statically (recommended for correct asset paths):

```bash
python -m http.server 8080
```
